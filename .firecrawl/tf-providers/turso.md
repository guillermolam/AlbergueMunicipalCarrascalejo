## [Schema](https://registry.terraform.io/providers/celest-dev/turso/latest/docs\#schema)

### [Required](https://registry.terraform.io/providers/celest-dev/turso/latest/docs\#required)

- [`organization`](https://registry.terraform.io/providers/celest-dev/turso/latest/docs#organization-1) (String) The name of the Turso organization

### [Optional](https://registry.terraform.io/providers/celest-dev/turso/latest/docs\#optional)

- [`api_token`](https://registry.terraform.io/providers/celest-dev/turso/latest/docs#api_token-1) (String, Sensitive) The API token to authenticate with Turso API. If not provided, the TURSO\_API\_TOKEN environment variable will be used. Finally, `turso auth token` is used to get the token.
