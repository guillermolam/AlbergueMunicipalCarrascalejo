# github\_repository\_environment

This resource allows you to create and manage environments for a GitHub repository.

## [Argument Reference](https://registry.terraform.io/providers/integrations/github/latest/docs/resources/repository_environment\#argument-reference)

The following arguments are supported:

- [`environment`](https://registry.terraform.io/providers/integrations/github/latest/docs/resources/repository_environment#environment-1) \- (Required) The name of the environment.

- [`repository`](https://registry.terraform.io/providers/integrations/github/latest/docs/resources/repository_environment#repository-1) \- (Required) The repository of the environment.

- [`wait_timer`](https://registry.terraform.io/providers/integrations/github/latest/docs/resources/repository_environment#wait_timer-1) \- (Optional) Amount of time to delay a job after the job is initially triggered.

- [`can_admins_bypass`](https://registry.terraform.io/providers/integrations/github/latest/docs/resources/repository_environment#can_admins_bypass-1) \- (Optional) Can repository admins bypass the environment protections. Defaults to `true`.

- [`prevent_self_review`](https://registry.terraform.io/providers/integrations/github/latest/docs/resources/repository_environment#prevent_self_review-1) \- (Optional) Whether or not a user who created the job is prevented from approving their own job. Defaults to `false`.


### [Reviewers](https://registry.terraform.io/providers/integrations/github/latest/docs/resources/repository_environment\#reviewers)

The `reviewers` block supports the following:

- [`teams`](https://registry.terraform.io/providers/integrations/github/latest/docs/resources/repository_environment#teams-1) \- (Optional) Up to 6 IDs for teams who may review jobs that reference the environment. Reviewers must have at least read access to the repository. Only one of the required reviewers needs to approve the job for it to proceed.

- [`users`](https://registry.terraform.io/providers/integrations/github/latest/docs/resources/repository_environment#users-1) \- (Optional) Up to 6 IDs for users who may review jobs that reference the environment. Reviewers must have at least read access to the repository. Only one of the required reviewers needs to approve the job for it to proceed.


#### Deployment Branch Policy

The `deployment_branch_policy` block supports the following:

- [`protected_branches`](https://registry.terraform.io/providers/integrations/github/latest/docs/resources/repository_environment#protected_branches-1) \- (Required) Whether only branches with branch protection rules can deploy to this environment.

- [`custom_branch_policies`](https://registry.terraform.io/providers/integrations/github/latest/docs/resources/repository_environment#custom_branch_policies-1) \- (Required) Whether only branches that match the specified name patterns can deploy to this environment.
