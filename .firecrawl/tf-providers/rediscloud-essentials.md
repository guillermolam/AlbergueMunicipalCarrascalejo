# Resource: rediscloud\_essentials\_subscription

This resource allows you to manage an Essentials subscription within your Redis Enterprise Cloud account.

Note:

This is for Essential Subscriptions only. See also `rediscloud_subscription` (Pro) and `rediscloud_active_active_subscription`.

Note:

It's recommended to create a Database (`rediscloud_essentials_database`) when you create a Subscription.

## [Argument Reference](https://registry.terraform.io/providers/RedisLabs/rediscloud/latest/docs/resources/rediscloud_essentials_subscription\#argument-reference)

The following arguments are supported:

- [`name`](https://registry.terraform.io/providers/RedisLabs/rediscloud/latest/docs/resources/rediscloud_essentials_subscription#name-1) \- (Required) A meaningful name to identify the subscription
- [`plan_id`](https://registry.terraform.io/providers/RedisLabs/rediscloud/latest/docs/resources/rediscloud_essentials_subscription#plan_id-1) \- (Required) The plan to which this subscription will belong
- [`payment_method_id`](https://registry.terraform.io/providers/RedisLabs/rediscloud/latest/docs/resources/rediscloud_essentials_subscription#payment_method_id-1) \- (Optional) If the plan is paid, this must be a valid payment method pre-defined in the current account

### [Timeouts](https://registry.terraform.io/providers/RedisLabs/rediscloud/latest/docs/resources/rediscloud_essentials_subscription\#timeouts)

The `timeouts` block allows you to
specify [timeouts](https://www.terraform.io/docs/configuration/resources.html#timeouts) for certain actions:

- [`create`](https://registry.terraform.io/providers/RedisLabs/rediscloud/latest/docs/resources/rediscloud_essentials_subscription#create-1) \- (Defaults to 30 mins) Used when creating the subscription
- [`update`](https://registry.terraform.io/providers/RedisLabs/rediscloud/latest/docs/resources/rediscloud_essentials_subscription#update-1) \- (Defaults to 30 mins) Used when updating the subscription
- [`delete`](https://registry.terraform.io/providers/RedisLabs/rediscloud/latest/docs/resources/rediscloud_essentials_subscription#delete-1) \- (Defaults to 10 mins) Used when destroying the subscription

## [Attribute reference](https://registry.terraform.io/providers/RedisLabs/rediscloud/latest/docs/resources/rediscloud_essentials_subscription\#attribute-reference)

- [`status`](https://registry.terraform.io/providers/RedisLabs/rediscloud/latest/docs/resources/rediscloud_essentials_subscription#status-1) \- The current status of the subscription
- [`creation_date`](https://registry.terraform.io/providers/RedisLabs/rediscloud/latest/docs/resources/rediscloud_essentials_subscription#creation_date-1) \- When the subscription was created
